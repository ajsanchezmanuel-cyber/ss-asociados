# S&S ASOCIADOS - Bufete de Abogados

Sitio web profesional para **S&S ASOCIADOS**, bufete de abogados en Quito, Ecuador.

## 🏛️ Sobre el Proyecto

Landing page moderna y responsiva que presenta los servicios legales del bufete, el equipo de socios fundadores e información de contacto.

## ⚖️ Especialidades

- Derecho Civil
- Derecho Laboral
- Derecho Familiar
- Mercantil y Corporativo
- Protección de Datos
- Trámites Notariales

## 🛠️ Tecnologías

- HTML5
- CSS3 (Variables CSS, Grid, Flexbox)
- JavaScript (Vanilla)
- Google Fonts (Playfair Display, Inter)
- Font Awesome 6
- FormSubmit.co (envío de formularios)
